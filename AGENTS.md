# LureLog project guidance

For work in this repository, use the LureLog product context in `.agents/skills/lurelog-product/SKILL.md` and consult `docs/product/lurelog-brief.md` for the requirements relevant to the task. The brief describes the product vision; inspect the current implementation and respect subsequent user decisions rather than assuming every requested feature is already implemented or rebuilding the project from scratch.

Keep changes focused on the user's request. Preserve the existing palette unless asked to change it. Make a separate commit for each requested change so it can be reverted independently.
